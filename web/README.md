# Веб-кабинет диспетчера и администратора

Кабинет для работы с компьютера: тот же Supabase, те же логины и пароли,
что и в мобильном приложении. Водители и грузчики сюда не входят — у них
мобильное приложение.

Что есть:

- **Календарь** — всегда 7 дней (пн–вс), стрелки по неделям, кнопка
  «Сегодня». День, месяц и год в шапке кликабельные: день — выбрать дату,
  месяц — выбрать месяц, год — выбрать год и месяц. Клик по пустому месту —
  новый заказ на это время. Заказ можно перетащить мышкой на другой день или
  время — кабинет спросит «Перенести» или «Скопировать сюда». Слева — фильтр
  по сотруднику.
- **Карточка заказа** (справа): статус, маршрут, бригада с отметкой «принял»,
  сумма; кнопки «Изменить», «Копировать», «Перенести», «Удалить».
- **Форма заказа** на весь экран: слева клиент, услуги, адреса, груз и сумма,
  справа водитель, машина и грузчики с точками доступности (зелёная —
  свободен, жёлтая — занят другим заказом, красная — выходной).
- **Заказы** — все заказы за период одной таблицей с фильтрами и поиском.
- **Клиенты** — вся база с поиском, сортировкой по любой колонке и быстрыми
  срезами; карточка клиента с историей заказов, выручкой и заметками.
- **Автопарк**, **График** (месяц сразу по всем сотрудникам), **Команда** и
  **Статистика** за выбранный период (последние два — только администратору).
- **Выгрузка** — клиенты или заказы за период в Excel или CSV, колонки
  выбираются галочками и запоминаются.

Права те же, что в мобильном приложении (`src/lib/permissions.ts` —
копия `mobile/src/lib/permissions.ts`): например, диспетчер без галочки
«телефоны и суммы» не увидит и не выгрузит их и здесь.

## Запустить на своём компьютере

Нужен [Node.js](https://nodejs.org) 20 или новее.

1. Скопируйте `web/.env.example` в `web/.env.local` и впишите те же два
   значения, что в `mobile/.env` (Supabase → Project Settings → API):
   `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
2. В терминале:
   ```bash
   cd web
   npm install
   npm run dev
   ```
3. Откройте http://localhost:3000 и войдите своим логином.

## Выложить в интернет (Vercel, бесплатно, без терминала)

1. Зайдите на https://vercel.com через GitHub → **Add New… → Project** →
   выберите репозиторий `md-trans`.
2. **Root Directory** — `web`.
3. В **Environment Variables** добавьте `NEXT_PUBLIC_SUPABASE_URL` и
   `NEXT_PUBLIC_SUPABASE_ANON_KEY` (те же значения).
4. **Deploy**. Через минуту Vercel даст адрес вида `https://md-trans.vercel.app`.

Можно и на любой другой хостинг: `npm run build` собирает готовый сайт в
папку `web/out/` — это обычные файлы, своего сервера кабинету не нужно.

## Push бригаде из кабинета

Когда диспетчер назначает бригаду или переносит заказ в кабинете, push
уходит через серверную функцию `send-push` (из браузера напрямую в Expo
отправить нельзя). Задеплойте её один раз:

```bash
supabase functions deploy send-push
```

Без неё кабинет работает, просто push из кабинета не придут.

## Изменений в базе нет

Кабинет работает на миграциях 0001–0007, новых миграций не требует.
